# Artefatos Complementares de Pesquisa

Este repositório contém o material complementar e a documentação do projeto apresentados no artigo científico:

> **Technical Debt in Software Documentation and Its Impact on Test Coverage**  
> *Lutero Lima Goulart, Yuska Paola Costa Aguiar, Michel Diniz Medeiros, Marcelo Iury de Sousa Oliveira* 
> Publicado em / Submetido ao: *Simpósio Brasileiro de Qualidade de Software 2026*

---

## Conteúdo do Repositório

O repositório está organizado com os seguintes arquivos e artefatos:

- `documentacao_requisitos.pdf`: Documento completo de especificação e formalização dos requisitos do sistema.
- `formulario_pesquisa.pdf`: Instrumento de coleta de dados / formulário utilizado na pesquisa com os participantes.

---

## Nota sobre Confidencialidade e Tarja de Dados

Por se tratar de um software desenvolvido em parceria com a **Universidade Federal da Paraíba (UFPB)** para utilização pelo **Governo do Estado da Paraíba**, determinadas informações contidas na documentação original foram **omitidas ou censuradas** (tarjadas).

> **Importante:** As edições e omissões realizadas limitam-se estritamente aos dados sensíveis e de infraestrutura, preservando integralmente a estrutura teórica, a metodologia de requisitos e a validade científica do material disponibilizado.
